***TikTok Live Bot***

A (what aims to be) fully functioning Python-coded bot for use by TikTok Livestreamers, as an alternative to paid-for apps such as Tikfinity and Tikops.

**How is this done?**
- TTS is ran through Piper; A commonly-used, robust TTS system with interchangable models and configs.
  > Piper is ran entirely locally, meaning that there is absolutely ZERO charge for using TTS as much as you want

  > TTS pulls from comments in order to keep up with an ever-flowing chat!

  > Piper can also read out gifts and who they are from, new follows and who's liking a live. (WIP)
    > Feature requests can be sent in to give ideas on what more to add

  > Script also features an automatic filtering system that can prevent Piper from speaking comments that contain bad language from bad actors (e.g,Trolls using TTS for slurs and other hate speech) (WIP)

- App is controlled through an app that runs entirely in your system tray
  > Configuration can be edited without having to dive into files (But for those who want to, the option is there.) (Started - WIP)

  > Bot can autoconnect to a live when its running and auto-disconnect when it ends

  > Bot can also be set up with autocommenting features aswell (WIP)
